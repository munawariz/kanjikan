One-line: Icon-only control — the corner arrow on cards, the hero play button, the app's quick actions.

```jsx
<IconButton icon="arrow-up-right" tone="accent" size="lg" label="Open" />
<IconButton icon="play" tone="sage" size="xl" label="Watch the film" />
```

Notes
- Circle by default; `shape="rounded"` (12px) for the app's Transfer/Request/PayBill tiles.
- Sizes 36 / 44 / 56 / 72px. Hover darkens; nothing scales.
