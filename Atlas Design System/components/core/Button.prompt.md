One-line: The Atlas action button — forest by default, lime for the single strongest CTA on a view.

```jsx
<Button>Send Money Now</Button>
<Button variant="accent" icon="chevron-right">View More</Button>
<Button variant="outline" shape="pill" size="sm">Open an Account</Button>
```

Notes
- Variants: primary (forest), accent (lime, forest label), outline, ghost, inverse (white on forest), outline-inverse.
- Sizes 40 / 48 / 58px. Radius 10px; `shape="pill"` only for the header account CTA.
- Hover darkens one step, press nudges down 1px. No scale, no shadow growth.
